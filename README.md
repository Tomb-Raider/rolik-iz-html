# Ролик из HTML

Пакет, чтобы собрать короткий ролик из HTML с любым ИИ, который пишет код: GigaChat, ChatGPT, Claude. Без After Effects и без установки программ

![Плеер с таймлайном по сценам](https://raw.githubusercontent.com/Tomb-Raider/rolik-iz-html/main/.github/player.png)

## Открыть без скачивания

Сайт пакета https://tomb-raider.github.io/rolik-iz-html/

- [Плеер](https://tomb-raider.github.io/rolik-iz-html/%D0%9F%D0%BB%D0%B5%D0%B5%D1%80.html) с примером на три сцены
- [Приёмы движения](https://tomb-raider.github.io/rolik-iz-html/%D0%9F%D1%80%D0%B8%D1%91%D0%BC%D1%8B%20%D0%B4%D0%B2%D0%B8%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F.html) стили, 11 приёмов и 6 принципов анимации вживую, у каждого источник и кнопка «Скопировать для ИИ»
- [Как разобрать референс](https://tomb-raider.github.io/rolik-iz-html/%D0%9A%D0%B0%D0%BA%20%D1%80%D0%B0%D0%B7%D0%BE%D0%B1%D1%80%D0%B0%D1%82%D1%8C%20%D1%80%D0%B5%D1%84%D0%B5%D1%80%D0%B5%D0%BD%D1%81.html) как замерить чужой ролик и описать движение словами
- [Если что-то не так](https://tomb-raider.github.io/rolik-iz-html/%D0%95%D1%81%D0%BB%D0%B8%20%D1%87%D1%82%D0%BE-%D1%82%D0%BE%20%D0%BD%D0%B5%20%D1%82%D0%B0%D0%BA.html) что видно в плеере и что написать ИИ

## Как скачать

Откройте [страницу пакета на GitHub](https://github.com/Tomb-Raider/rolik-iz-html), нажмите зелёную кнопку «Code», затем «Download ZIP». Распакуйте архив и откройте `Плеер.html` двойным щелчком. Ссылки наверху HTML-страниц переключают страницы пакета, проверено в Chrome

Пошагово в [Как пользоваться](https://github.com/Tomb-Raider/rolik-iz-html/blob/main/%D0%9A%D0%B0%D0%BA%20%D0%BF%D0%BE%D0%BB%D1%8C%D0%B7%D0%BE%D0%B2%D0%B0%D1%82%D1%8C%D1%81%D1%8F.md). Там два пути, через чат и через агента в папке, клавиши плеера и как менять длину сцен
